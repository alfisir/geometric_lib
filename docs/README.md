# Документация Geometric Lib

## Общее описание решения
Библиотека на Python для удобного расчета площадей и периметров геометрических фигур (круга и квадрата).

## Описание функций с примерами вызова

### Модуль circle.py
* **area(r)** — Возвращает площадь круга по его радиусу.
  * *Пример:* `area(3)` -> `28.274333882308138`
* **perimeter(r)** — Возвращает длину окружности.
  * *Пример:* `perimeter(3)` ->
  *  `18.84955592153876`

### Модуль square.py
* **area(a)** — Возвращает площадь квадрата со стороной a.
  * *Пример:* `area(5)` -> `25`
* **perimeter(a)** — Возвращает периметр квадрата.
  * *Пример:* `perimeter(5)` -> `20`
